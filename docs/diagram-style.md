# Groundbreakers engineering diagram theme

Visual-only portfolio standard: midnight `#10101D`, indigo graphite `#2A2A3D`, lavender `#B8B8FF`, off-white `#F0F0FF`. Amber `#E3BC7F` means held/uncertain, teal `#81C5B0` means verified or published, not production certification. IBM Plex Sans with sans-serif fallback is used for SVG node labels. README Mermaid remains machine-readable; its graph topology was not changed.

The historical Mermaid render evidence is preserved in `docs/evidence/diagram-rendering.json` with a clear distinction between the original render and the new visual style. The static `architecture.svg` is independently maintained and isn't presented as an exact output of that earlier Mermaid renderer.
